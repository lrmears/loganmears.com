# loganmears.com

Hand-written static site: HTML, CSS and ES modules. No build step, no dependencies.
Everything deployable lives in `site/` and is published by `.github/workflows/pages.yml`.

- `site/index.html`: all content (hero, timeline, games, toolkit, contact)
- `site/assets/styles.css`: design system, light/dark themes
- `site/assets/js/`: `main.js` (entry), `wordle.js`, `cipher.js`, `palette.js` (Cmd+K), `sound.js`, `words.js`

## Running stats
`site/assets/js/running-data.js` is generated by `scripts/running_data.py` from a JSON list of runs
(kept outside the repo). It writes only aggregates: no routes, titles, heart rate or per-run dates.
A scheduled Claude task ("Twice-weekly running stats update") refreshes it on Mondays and Thursdays
around 7 AM, while the Claude desktop app is open. It reads recent runs from COROS, regenerates the
file, runs privacy and sanity checks, then opens a PR and merges it itself, which triggers a deploy.
If a check fails, it publishes nothing and reports why. If no new runs are found, it makes no commit.

## GeoTrace country outlines
`site/assets/js/outlines.js` is generated by `scripts/build_outlines.py` from the world-atlas
`countries-110m.json` (Natural Earth, public domain). Download that file once, keep it outside the
repo, and run the script. The outlines load lazily the first time a guess is made.

Preview locally: `python3 -m http.server --directory site 8000`, then open http://localhost:8000.
