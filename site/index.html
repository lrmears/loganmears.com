03 · Play

GeoTrace

A short, security-themed game. Investigate a simulated intrusion alert, use recon clues to work out where it originated, and name the country. A new case is available every day.

Daily
analyst@soc: ~

        
      

    

  


  
    

    
How to play GeoTrace

    
Goal: identify which country an attack came from in 6 guesses or fewer, using as few recon commands as you can.

    
    
      
  1. Investigate. Run recon commands in the terminal. Each reveals one clue about the attacker's connection.
    2. 
      
  2. Guess. Type guess <country> (for example guess japan). Press Tab to autocomplete country names.
    3. 
      
  3. Read the feedback. A wrong guess shows how far away the answer is, which direction it lies in, and a closeness percentage.
    4. 
    

    
Recon commands

    

      
whois
The country-code domain (like .fr) of the attacker's registrant.

      
ping
Round-trip latency from the Omaha sensor. Farther away means slower.

      
tz
The timezone in the attacker's session logs.

      
lang
The browser's language header, like ja-JP.

      
phone
The country calling code of the MFA text-message number.

      
continent
The region the attacker's network is registered in.

      
traceroute
The network path. The last hop is named after the capital city, which is the biggest clue.

    

    
Other commands

    
help, countries (all valid answers), history, clear, and new for a practice case. Use ↑ and ↓ to recall earlier commands.

    
Reading a guess

    
✗ Japan: 13,501 km W ⬅️ (32% close)

    
That means the answer is about 13,500 km west of Japan. The closer to 100%, the warmer you are.

    
Good to know

    
    
      
  • The daily case is the same for everyone and resets at midnight. Your progress is saved in this browser.
    • 
      
  • Sharing copies a spoiler-free emoji summary of your result.
    • 
      
  • The incident is fictional, and the IP address is from a reserved documentation range.
